# Documentación — Grupo 3 IOP 2026

Documentación técnica de la app web de algoritmos de redes (Prim, Kruskal,
Dijkstra, Ford-Fulkerson, CPM y PERT). Pensada para entender el proyecto sin
tener que leer todo el código fuente primero.

1. [Visión general](./00-vision-general.md) — qué es, qué resuelve, puntos clave.
2. [Arquitectura](./01-arquitectura.md) — organización de carpetas, flujo de datos, cómo sumar un algoritmo nuevo.
3. [Algoritmos](./02-algoritmos.md) — los seis algoritmos explicados a partir de la implementación real.
4. [Casos de uso](./03-casos-de-uso.md) — todo lo que se puede hacer con la app, de punta a punta.
5. [Diagramas](./04-diagramas.md) — diagrama de componentes y diagramas de secuencia (Mermaid).

Otros documentos, en la raíz del repo:

- [`README.md`](../README.md) — instalación, ejecución (`npm install`,
  `npm run dev`, `npm test`), formatos de carga y configuración.
- [`MANUAL.md`](../MANUAL.md) — cada algoritmo en nivel funcional y técnico,
  con trazas de los ejemplos, referencias a líneas de código y qué pasa si se
  modifica cada parte.
- [`ENTREGA.md`](../ENTREGA.md) — cumplimiento de la consigna, guía para la
  demostración y respuestas a las preguntas sobre el desarrollo.
- [`INFORME.md`](../INFORME.md) — informe de avance (también visible en la
  app, en `/informe`).
